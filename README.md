# Automechnics

Next.js marketing website design preview. Run `npm install` then `npm run dev` and open http://127.0.0.1:3000.

Includes a homepage, interactive vehicle selector, eight service screens, services directory and enquiry preparation flow. Enquiry details remain in the browser; no lead is submitted until a real delivery integration is configured.

## Before launch

- Supply verified business name, locations, opening hours and contact details.
- Confirm packages, inclusions, pricing, timing and warranties.
- Replace labelled illustrative workshop imagery with real workshop photography.
- Configure enquiry delivery, privacy information, analytics and final domain metadata.
- Remove preview noindex metadata only when ready to launch.

## Assets

`public/images/workshop.png` is AI-generated illustrative photography. `public/images/logo-concept.png` is a generated logo exploration. The site uses a crisp scalable SVG monogram and live wordmark rather than raster text.
